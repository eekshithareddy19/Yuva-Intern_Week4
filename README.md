# Yuva-Intern_Week4
Developed a comprehensive data analysis report using R and the Iris dataset. Integrated data cleaning, exploratory analysis, visualization, and Decision Tree classification. Evaluated model performance using test data and a confusion matrix, and documented key insights, challenges, results, and future scope.

## Dataset
The Iris dataset was used, containing 150 observations from three species: Setosa, Versicolor, and Virginica.

## Methodology
The project followed these major steps:
1. Data inspection and preparation
2. Data cleaning
3. Exploratory data analysis
4. Data visualization
5. Predictive modeling
6. Model evaluation
7. Insight communication

## Tools and Technologies
- R Programming
- ggplot2
- rpart
- rpart.plot
- Iris Dataset

## Visualization
Multiple charts were used, including bar charts, scatter plots, histograms, box plots, and line charts.

## Predictive Modeling
A Decision Tree classification model was used to predict iris species based on sepal and petal measurements. Model performance was evaluated using test data and a confusion matrix.

## Key Findings
Petal length and petal width were particularly useful for distinguishing the three iris species. The analysis demonstrated how visualization and predictive modeling can work together to support data-driven decisions.
